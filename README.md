## 🧒 Explain Like I'm 5

Think of a team of robot inspectors that read computer code the way editors read a book draft. One robot checks for bugs, another looks for security holes, another checks style — and together they write a review report, just like a senior engineer would. That's CodeSentinel: an AI team that reviews code automatically.

## 🧰 Tech Stack

Python · multi-agent LLM orchestration · static analysis · vulnerability detection heuristics

## 🌍 Real-Life Applications

- Automated first-pass code review on pull requests before a human looks
- Catching common security vulnerabilities early in development
- Teaching tool — junior developers learn from the agents' explanations
